# emaki.lol

Docs site for [Emaki](https://github.com/alkaline-software/emaki), built with
[Quarto](https://quarto.org).

## Develop

```sh
quarto preview
```

## Deploy

Pushing to `main` runs `.github/workflows/publish.yml`, which renders the site
and pushes it to the `gh-pages` branch. Netlify serves `emaki.lol` from that
branch.

## How it is put together

`docs/design.md` is the standard the site is held to: the rules, the
palette and its roles, the faces, the elements and the motion. The
neutrals and the faces are the app's (`emaki/crates/emaki-app/themes/emaki.json`,
`emaki/docs/look.md`); the colours are the icon's. Tokens live in
`css/theme.scss`, the dark appearance's Bootstrap knobs in `css/dark.scss`,
and the icons in `assets/icons/` are the app's own Tabler files, drawn
through CSS masks. `js/page.js` marks the visitor's system among the
downloads and lets the landing page's bands rise into view.

`_hero.html` is the handscroll on the landing page, a port of the app's own
figure (`Workbench::home_scroll`). Its four landscape layers are generated by
`scripts/home-scroll.py` in the app repo and inlined so they inherit
`currentColor`; re-copy them rather than editing them. `js/hero-scroll.js`
runs the spring that winds it under the pointer, with the app's own constants.

`js/navbar-widgets.js` adds a dark-mode toggle, a keyboard-shortcuts button
(press `?`), and a GitHub stars/forks dropdown. It reads the owner and repo
from the navbar's GitHub link, which points at the app.

`scripts/fetch-releases.sh` writes `_releases.md` from the app's GitHub
releases as a Quarto pre-render step. `_releases.md` is committed, and the
script fails soft, so an offline preview or a rate limit leaves the last good
copy in place instead of breaking the build.

# emaki.lol

Docs site for [Emaki](https://github.com/alkaline-software/emaki), built with
[Quarto](https://quarto.org).

## Develop

```sh
quarto preview
```

## Deploy

Pushing to `main` runs `.github/workflows/publish.yml`, which renders the site
and pushes it to the `gh-pages` branch. Netlify serves `emaki.lol` from that
branch.

## How it is put together

`docs/design.md` is the standard the site is held to: the rules, the
palette and its roles, the faces, the elements and the motion. The
neutrals and the faces are the app's (`emaki/crates/emaki-app/themes/emaki.json`,
`emaki/docs/look.md`); the colors are the icon's. Tokens live in
`css/theme.scss`, the dark appearance's Bootstrap knobs in `css/dark.scss`,
and the icons in `assets/icons/` are the app's own Tabler files, drawn
through CSS masks. `js/page.js` names this computer's installer on the
landing page's download and marks it among the Get Started page's tiles, and
lets the landing page's bands rise into view.

`js/figures.js` is the landing page's figures: Hairline's engine
(`@lucasmarkes/hairline`, MIT) and six figures of Emaki's own
parts drawn on its core (`scripts/figures/emaki/`).
`scripts/figures/build.sh` builds it from Hairline's repository at a pinned
tag; the output is committed, so a render needs no Node. Each docs page
opens on a sketch of the app's window, one base drawn for all of them
with that page's part in color and the rest gray (`docs/_sk/`, written by
`scripts/sketches/gen.py`), answering the pointer through
`js/sketches.js`. `_shift-ide.html` and `_shift-ade.html` are the
sketch under "From the IDE to the ADE", two windows drawn by hand with
their panes named, one a row with its words beside it, and `js/shift.js`
is how they answer the pointer.

`_hero.html` is the handscroll on the landing page, a port of the app's own
figure (`Workbench::home_scroll`). Its four landscape layers are generated by
`scripts/home-scroll.py` in the app repo and inlined so they inherit
`currentColor`; re-copy them rather than editing them. `js/hero-scroll.js`
runs the spring that winds it under the pointer, with the app's own constants.

`js/navbar-widgets.js` puts the app's latest version in the navbar, read
from its GitHub releases, adds a dark-mode toggle and a GitHub stars/forks
dropdown, and opens the search on ⌘F (Ctrl+F elsewhere). It reads the owner
and repo from the navbar's GitHub link, which points at the app.

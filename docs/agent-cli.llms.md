# Agent CLI ⌘⇧L

Your agent’s own screen, in the chat’s place.

If you want your agent’s original CLI, this is it. The Agent CLI is Claude Code’s or Codex’s own screen, running the same session, and it takes the chat’s place. Move the pointer to the chat’s right margin and a seam appears, a line down the margin with a knob halfway. Click the knob, or press ⌘⇧L, and the terminal slides in over the chat; the same seam switches back. The app calls the two the CLI layout and the rendered layout, and each tab keeps the one you chose for it.

A message typed in either shows in the other, so you can continue the session in whichever you like. As in the [Terminal Panel](../docs/terminal.llms.md), you can use your mouse, scrolling, and keyboard shortcuts. The [Outline](../docs/outline.llms.md) folds away with the chat and comes back with it.

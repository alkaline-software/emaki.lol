# Outline Panel

⌘⇧O: a short label for every prompt, to find your way back through a long session.

## Entries

Going back through a long session is a pain. The outline gives each prompt one entry, under a heading for each day: the time, then three to five words for what you asked. A short prompt is shown as it is. A long one is labeled by the agent’s small model, Haiku for Claude Code and Codex’s light model for Codex, in a separate session, so nothing enters yours. Labels are made for the entries in view, a few at a time, and kept, so each prompt is labeled once.

## Going back

Click an entry and the chat glides back to that round. As you scroll, the entry in view is highlighted, so the outline always shows where you are. It shares the left side with the [files](../docs/files.llms.md): one shows at a time, and switching does not move the chat.

# Shell Terminal Panel

⌘⇧S: a shell in the project’s folder, in tabs beside the chat.

## A shell where the work is

Opening a terminal and `cd`-ing to the project is easy, but doing it again and again is a pain. The shell terminal opens your login shell in the session’s folder, at the chat’s right. Shells are tabs: the **+** or ⌘T opens one, ⌘W closes it, ⌘K clears the screen, and you can drag tabs to reorder them. They stay open until you close them or quit.

Paste a picture and it lands as the path of a file. A selection can copy itself when you let go (Settings, Terminal). Programs that use the mouse get its clicks and scrolls, and the Mac’s line keys work (⌘←, ⌘→, ⌘⌫). The look is inspired by [Kaku](https://kaku.fun), in the window’s own colors and font.

The same shell opens beside the install steps on the Agents page, for the commands they give. It shares the right side with the [agent terminal](../docs/agent.llms.md): one shows at a time.

# Keys

A collection of all keyboard commands on Emaki.

⌘ on macOS, Ctrl elsewhere.

## Panels

Hold ⇧ with ⌘, and the letter shows or hides something beside the chat, or switches what shows. The letter is the thing’s first, and B is the sidebar’s.

|  |  |
|----|----|
| ⌘⇧B | the sidebar, with your [projects](../docs/projects.llms.md) and their sessions; ⌘B too |
| ⌘⇧F | [Files Panel](../docs/files.llms.md) |
| ⌘⇧S | [Terminal Panel](../docs/terminal.llms.md) |
| ⌘⇧O | the [Outline](../docs/outline.llms.md)’s drawer |
| ⌘⇧L | the layout: the [Agent CLI](../docs/agent-cli.llms.md) in the chat’s place, or the chat |
| ⌘⇧G | git’s [Changes](../docs/files.llms.md#git) sheet |
| ⌘⇧V | a file in the [Files Panel](../docs/files.llms.md) as it reads, or as it is written |

## Pages

⌘ and a letter opens a page or a sheet over the window.

|     |                             |
|-----|-----------------------------|
| ⌘K  | search every session        |
| ⌘N  | new session                 |
| ⌘T  | new session in this project |
| ⌘O  | choose a folder             |
| ⌘L  | All Sessions                |
| ⌘E  | Agents                      |
| ⌘,  | Settings                    |

The rest of ⌘ each does one thing where you are.

|  |  |
|----|----|
| ⌘F · ⌘G | find in this chat, and the next hit; ⌘⇧G is the previous while the find bar is open |
| ⌘↩︎ | send, or commit in the Changes sheet |
| ⌘P | push, in the Changes sheet |
| ⌘S | save the file |
| ⌘1 to ⌘9 | tabs |
| ⌘W · ⌘⇧T | close a tab, reopen the last |
| ⌘⇧N | new branch |
| ⌘R | refresh |
| Esc | stop, or close what is open |

In the terminal, ⌘T or ⌘N opens a tab, ⌘W closes it and ⌘K clears the screen.

## Your own

[Settings, Shortcuts](../docs/settings.llms.md#shortcuts), changes the keys of the window’s commands above, and of the file editor’s Sublime Text commands. A key already taken is refused, and a button puts a changed key back.

# Keys

A collection of all keyboard commands on Emaki.

⌘ on macOS, Ctrl elsewhere.

## Panels

Hold ⇧ with ⌘, and the letter shows or hides a panel beside the chat. The letter is the panel’s first, and B is the sidebar’s.

|  |  |
|----|----|
| ⌘⇧B | the sidebar, with your [projects](../docs/projects.llms.md) and their sessions; ⌘B too |
| ⌘⇧F | [Files Panel](../docs/files.llms.md) |
| ⌘⇧O | [Outline Panel](../docs/outline.llms.md) |
| ⌘⇧S | [Shell Terminal Panel](../docs/terminals.llms.md#shell) |
| ⌘⇧A | [Agent Terminal Panel](../docs/terminals.llms.md#agent) |
| ⌘⇧G | git’s [Changes](../docs/files.llms.md#git) sheet |

## Pages

⌘ and a letter opens a page or a sheet over the window.

|     |                             |
|-----|-----------------------------|
| ⌘K  | search every session        |
| ⌘N  | new session                 |
| ⌘T  | new session in this project |
| ⌘O  | choose a folder             |
| ⌘L  | All Sessions                |
| ⌘E  | Agents                      |
| ⌘,  | Settings                    |

The rest of ⌘ each does one thing where you are.

|  |  |
|----|----|
| ⌘F · ⌘G | find in this chat, and the next hit; ⌘⇧G is the previous while the find bar is open |
| ⌘↩︎ | send, or commit in the Changes sheet |
| ⌘P | push, in the Changes sheet |
| ⌘S | save the file |
| ⌘1 to ⌘9 | tabs |
| ⌘W · ⌘⇧T | close a tab, reopen the last |
| ⌘⇧N | new branch |
| ⌘R | refresh |
| Esc | stop, or close what is open |

In the terminal, ⌘T opens a tab, ⌘W closes it and ⌘K clears the screen.
